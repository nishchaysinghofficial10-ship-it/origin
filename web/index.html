Research lifecycle

A loop designed
to prove itself wrong.

ORIGIN does not stop when a result looks persuasive. It searches for boundary conditions, demands replication, preserves contradictions, and records why it stopped.

06 / HONEST BOUNDARIES

What ORIGIN
does not claim.

Trust starts by naming the edge of the evidence.

  • 01
    Not a general autonomous scientist

    It runs registered computational domains: sorting and shortest-path benchmarks.

  • 02
    Not kernel-grade isolation

    Experiment confinement is user-space. A public worker requires an additional container boundary.

  • 03
    Not a source-discovery engine

    It can retrieve approved HTTPS URLs; it does not search or crawl the web.

  • 04
    Not live-provider verified

    The Anthropic transport remains unverified because no funded API key was available.

  • 05
    Not a medical, legal, or financial tool

    Its evidence applies only to its explicitly supported computational domains.
